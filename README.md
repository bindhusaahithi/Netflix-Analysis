## 📌 Project Overview

Performed comprehensive **Exploratory Data Analysis** on Netflix's content catalog to uncover trends in content type, ratings, release years, regional distribution, and genre popularity.

Built an interactive dashboard that allows users to filter and explore the data in real time.

---

## 🎯 Key Questions Answered

- How has Netflix content grown over the years?
- What's the split between Movies vs TV Shows?
- Which countries produce the most Netflix content?
- What are the most common ratings and genres?
- Who are the most prolific directors on Netflix?

---

## 📊 Key Findings

| Insight | Finding |
|---|---|
| 🎬 Content Split | **70.3%** Movies vs **29.7%** TV Shows |
| 🌍 Top Country | **United States** with 3,593 titles |
| 📅 Peak Year | Content additions peaked in **2019** |
| ⭐ Top Rating | **TV-MA** is the most common rating |
| 🎭 Top Genre | **International Movies** leads with 2,748 titles |
| 🎬 Top Director | **Rajiv Chilaka** with 22 titles |

## 🌐 Interactive Features

The live dashboard includes:
- **Filter by content type** — Movies or TV Shows
